# d4d-practice

Practice repository for Designing for Development, Week 2. Used to
learn core Git and GitHub workflows: committing, pushing, branching,
merging, and recovering from mistakes.

## What I did

- Created the repository and made an initial commit of the starter files
- Fixed a broken TODO comment in index.html
- Created a branch, changed the header background color in styles.css,
  committed it, and merged it back into main
- Practiced recovering from an uncommitted mistake using git restore
- Committed and pushed an unwanted change, then undid it with
  git revert instead of deleting it
- Wrote a recovery note documenting both exercises (see notes.md)
